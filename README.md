# Wordframe

Тренажёр английской лексики для русскоязычных учащихся. Есть карточки A1–B2 и отдельный раздел «Casualties Unknown». Нажмите на подчёркнутое слово в примере, чтобы увидеть его значение.

## Запуск

Откройте `dist/index.html` в браузере. Для статического хостинга используйте папку `dist`. Прогресс хранится в браузере. Для озвучки используются установленные в браузере голоса.

## Лексика

Дополнительные примеры лежат в `vocabulary-a2.txt`, `vocabulary-b1.txt` и `vocabulary-b2.txt`. Строки содержат часть речи, предложение с пометками и перевод. Конструкция `[слово=перевод]` задаёт изучаемое слово. Запись `word=перевод` задаёт значение вспомогательного слова в этой фразе. Текст хранится в UTF-8.

Раздел «Casualties Unknown» хранится в `vocabulary-casualties-unknown.txt`. Каждая карточка содержит перефразированную игровую ситуацию из английской локализации и простой пример с тем же словом или выражением. В тренажёре между примерами можно переключаться, а в сохранённой карточке словаря видны оба примера. В исходном файле поля разделяются символом `|`, изучаемое выражение в предложении выделяется квадратными скобками.

После изменения базы выполните `node compile-vocabulary.cjs`. Скомпилированные карточки находятся в `dist/words.js`. GitHub Pages публикует папку `docs`, поэтому перед отправкой изменений скопируйте обновлённые файлы из `dist` в `docs`.
