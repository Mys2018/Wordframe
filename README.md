# Wordframe

Тренажёр английской лексики для русскоязычных учащихся. Выберите уровень A1–B2 или подборку «Casualties Unknown» и при желании отфильтруйте карточки по части речи. Для фразовых глаголов есть своя вкладка. Нажмите на подчёркнутое слово в примере, чтобы увидеть его значение.

В тренажёре три режима. В **EN → RU** и **RU → EN** нужно выбрать перевод слова или выражения, а в режиме **Пропуски** — ввести нужную английскую форму. Подборки и ответы сохраняются отдельно для каждого режима.

Во вкладке **Грамматика** собраны правила и двуязычные примеры по временам, условным предложениям и другим темам. Из правила можно сразу перейти к упражнениям по теме. Материалы хранятся в `dist/grammar.js`.

## Генерация примеров

Сервер Wordframe добавляет кнопки генерации в словарные карточки, правила и задания с пропусками. Он обращается к PlusVibe с моделью `claude-haiku-5.5`. Ключ нужен только серверу.

Для локального запуска запишите `PLUSVIBE_API_KEY` в файл `.env` в формате `ИМЯ=значение`. Git игнорирует этот файл. Запустите `node --env-file=.env server.cjs` и откройте `http://127.0.0.1:8080`.

Для доступа с телефона через интернет разместите Node-сервер на хостинге с HTTPS. Задайте `PLUSVIBE_API_KEY` и `WORDFRAME_PASSWORD` как секреты хостинга, установите `HOST=0.0.0.0` и запустите `node server.cjs`. Имя пользователя для входа — `wordframe`. GitHub Pages по-прежнему публикует статическую версию. Прогресс хранится отдельно для каждого адреса сайта.

## Запуск

Откройте `dist/index.html` в браузере. Для статического хостинга используйте папку `dist`. Прогресс хранится в браузере. Для озвучки используются установленные в браузере голоса.

## Лексика

Дополнительные примеры лежат в `vocabulary-a2.txt`, `vocabulary-b1.txt` и `vocabulary-b2.txt`. Строки содержат часть речи (`n`, `v`, `a` или `p` для фразовых глаголов), предложение с пометками и перевод. Конструкция `[слово=перевод]` задаёт изучаемое слово. Запись `word=перевод` задаёт значение вспомогательного слова в этой фразе. Текст хранится в UTF-8.

Лексика «Casualties Unknown» хранится в `vocabulary-casualties-unknown.txt` и также входит в общие уровни A2–B2. Каждая карточка содержит перефразированную игровую ситуацию из английской локализации и простой пример с тем же словом или выражением. В тренажёре между примерами можно переключаться, а в сохранённой карточке словаря видны оба примера. В исходном файле поля разделяются символом `|`, изучаемое выражение выделяется квадратными скобками. Последнее поле задаёт ориентировочный уровень карточки.

Лексика про выживание и снаряжение лежит в `vocabulary-casualties-unknown-survival.txt` в том же формате. Переводы слов из игровых примеров и уточнения к отдельным фразам лежат в `vocabulary-casualties-unknown-glosses.txt`. После изменения базы выполните `node compile-vocabulary.cjs`. Скомпилированные карточки находятся в `dist/words.js`. GitHub Pages публикует папку `docs`, поэтому перед отправкой изменений скопируйте обновлённые файлы из `dist` в `docs`.
